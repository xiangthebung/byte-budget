    How Byte Budget measures usage

    Totals use the best information available from Chrome and each site. If an exact size is unavailable, Byte Budget makes a clearly labelled estimate.

    The measured percentage covers response bodies and nothing else. Header overhead is counted from the names and values and then halved, because HTTP/2 compresses headers by an amount Chrome does not report; WebSocket frames are invisible to an extension; a cancelled response counts as zero. So 100% measured means every body was measured, not that the total is exact.

    Every figure here covers this Chrome profile. A second profile, another browser, a native app, an operating system update and every other device on the same connection are invisible to an extension — there is no API that would show them. A carrier's figure can be several times larger, and the difference is not an error in this one.
