    Privacy & data

    Stored on this device

    Byte Budget records bytes per site per day and per hour, which hosts a site's bytes came from, and one row per page load holding the site and origin — never a path or a query string. It has no account, no server and makes no network request of its own. Preferences follow you through Chrome sync; site names, limits and exceptions do not leave this profile. All of it covers this Chrome profile on this device: other profiles, other browsers, other devices on the same connection and everything outside Chrome are invisible to an extension.

    Export

    One row per site per day, as stored: the date, the site, bytes down and up, requests, and how much of the down figure was estimated rather than measured.
